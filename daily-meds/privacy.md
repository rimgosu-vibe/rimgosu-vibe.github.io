# 약을매일먹자 개인정보처리방침

**앱 이름**: 약을매일먹자 (dev.rimgosu.dailymeds) — Android
**최종 수정일**: 2026년 11월 17일

## 요약

이 앱은 **개인정보를 수집하지 않습니다.** 개발자의 서버가 없고, 사용자가 입력한 알람과 기록은 기기 안에만
남습니다. 다만 무료로 제공하기 위해 Google AdMob 배너 광고를 보여 주며, 광고를 받는 과정에서 Google 이
아래 '광고' 항목의 정보를 처리할 수 있습니다.

## 앱이 저장하는 정보

앱은 다음을 **기기 내부의 앱 전용 저장 영역**에만 저장합니다.

| 항목 | 내용 |
|------|------|
| 알람 | 제목, 시각, 반복 요일, 색, 예고 알림·소리·진동 설정, 삭제한 알람이면 삭제한 시각 |
| 기록 | 날짜, 예정 시각, 기록 버튼을 누른 시각, 미룬 횟수 |
| 설정 | 화면 테마 (시스템 설정 따르기 · 라이트 · 다크), 광고 제거 구매 여부 |

재부팅한 뒤 잠금을 한 번도 풀지 않은 상태에서도 알람이 제시각에 울리도록, 이 데이터를
**기기 보호 저장소**(Direct Boot)에 둡니다. 다른 앱이나 외부에서는 접근할 수 없는 앱 전용 영역입니다.

이름·전화번호·이메일·생년월일·연락처·사진 등은 요청하지도, 저장하지도 않습니다.
알람 제목은 사용자가 직접 적은 문자열이며, 앱은 그 내용을 해석하거나 분류하지 않습니다.
기록은 사용자가 버튼을 눌러 직접 남기는 자가기록이고, 앱이 실제 복용 여부를 판단하지 않습니다.

## 외부 전송

**알람과 기록은 외부로 보내지 않습니다.** 위 표의 정보는 기기 밖으로 나가지 않으며, 광고에도 쓰이지 않습니다.

### 광고 (Google AdMob)

홈 화면 위쪽과 캘린더 화면 아래쪽에 Google AdMob 배너 광고가 나옵니다. 광고를 받기 위해 앱은 인터넷을
사용하고, AdMob SDK 는 Google 정책에 따라 다음 정보를 Google 에 보낼 수 있습니다.

- 광고 ID(Android 광고 ID), 기기·운영체제 정보, IP 주소로 추정한 대략적인 위치
- 광고 노출·클릭 같은 광고 상호작용 정보, 비정상 종료·진단 정보

이 정보는 광고를 보여 주고, 광고 성과를 측정하고, 부정 클릭을 막는 데 쓰입니다. 자세한 내용은 Google 의
[파트너 사이트·앱의 데이터 사용 방식](https://policies.google.com/technologies/partner-sites)을 따릅니다.
광고 맞춤 설정은 기기 설정 → Google → 광고 에서 끄거나 광고 ID 를 삭제할 수 있습니다.
유럽경제지역·영국·스위스 사용자에게는 광고 전에 동의를 묻고, 앱 설정의 '광고 개인정보 설정'에서 바꿀 수 있습니다.

알람이 울리는 화면·알림·잠금화면에는 광고가 나오지 않습니다. 이 앱은 분석·추적 SDK 를 따로 넣지 않으며,
제3자에게 개인정보를 판매하지 않습니다.

### 광고 제거 결제 (Google Play 결제)

설정의 '광고 제거'(1,900원, 한 번 결제로 평생)는 Google Play 결제로 처리됩니다. 결제 정보는 Google 이 받고,
앱은 구매했는지 여부만 Play 에 확인해 기기에 기억합니다. 같은 Google 계정이면 기기를 바꿔도 구매가 복원됩니다.

### 기기 백업

기기에서 Google 백업을 켜 두었다면 알람과 기록이 사용자 본인의 Google 계정 백업에 포함되고, 새 기기로
옮길 때 함께 복원됩니다. 이 백업은 Google 과 사용자 사이의 기능이며 앱 개발자는 해당 데이터에 접근할 수
없습니다. 원하지 않으면 기기 설정에서 이 앱의 백업을 끌 수 있습니다.

앱 안의 '리뷰 쓰기', '개인정보처리방침', '문의하기'는 사용자가 누를 때만 스토어·브라우저·메일 앱을
열 뿐이며, 앱이 그 과정에서 정보를 보내지 않습니다.

## 권한

| 권한 | 쓰는 이유 |
|------|-----------|
| 알림 (POST_NOTIFICATIONS) | 알람 알림을 띄우기 위해 |
| 정확한 알람 (SCHEDULE_EXACT_ALARM · USE_EXACT_ALARM) | 정해진 시각에 정확히 울리기 위해 |
| 전체 화면 알림 (USE_FULL_SCREEN_INTENT) | 잠금화면 위에 알람 화면을 띄우기 위해 |
| 포그라운드 서비스 (FOREGROUND_SERVICE · MEDIA_PLAYBACK) | 알람음을 끊기지 않게 재생하기 위해 |
| 부팅 완료 (RECEIVE_BOOT_COMPLETED) | 재부팅 후 알람을 다시 예약하기 위해 |
| 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW) | 다른 앱을 쓰는 중에도 알람 화면을 띄우기 위해 |
| 배터리 최적화 제외 (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) | 절전 기능에 알람이 밀리지 않게 하기 위해 |
| 진동 (VIBRATE) · 화면 깨우기 (WAKE_LOCK) | 알람 진동과 화면 켜기 |
| 인터넷 (INTERNET) · 광고 ID (AD_ID) | 광고를 받기 위해 (알람·기록은 보내지 않습니다) |
| 결제 (BILLING) | 광고 제거를 Google Play 결제로 구매하기 위해 |

인터넷·광고 ID·결제를 뺀 권한은 모두 알람을 제 시각에 울리기 위한 용도이며, 개인정보를 읽는 데 쓰이지 않습니다.

## 데이터 삭제

- 알람 삭제: 앱 안에서 알람을 삭제하면 더 울리지 않지만, 지난 기록은 캘린더에 남습니다.
  삭제할 때 **기록도 함께 지우기**를 고르면 그 알람과 기록이 함께 지워집니다. 기록이 없는 알람은
  삭제하면 바로 지워집니다.
- 전체 삭제: **설정 → 애플리케이션 → 약을매일먹자 → 저장공간 → 데이터 삭제**, 또는 앱 삭제.
  기기에 저장된 모든 데이터가 삭제됩니다.
- 개발자가 보관하는 사본이 없으므로, 개발자에게 삭제를 요청할 데이터도 없습니다.
  광고 관련 정보는 Google 이 관리하며, 기기 설정에서 광고 ID 를 삭제하거나 재설정할 수 있습니다.
