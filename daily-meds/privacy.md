# 약을매일먹자 개인정보처리방침

**앱 이름**: 약을매일먹자 (dev.rimgosu.dailymeds) — Android · iOS
**최종 수정일**: 2026년 10월 13일

## 요약

이 앱은 **개인정보를 수집하지 않습니다.** 서버가 없고, 앱이 데이터를 외부로 보내는 기능 자체가
없습니다. 사용자가 입력한 내용은 기기 안에만 남습니다.

## 앱이 저장하는 정보

앱은 다음을 **기기 내부의 앱 전용 저장 영역**에만 저장합니다.

| 항목 | 내용 |
|------|------|
| 알람 | 제목, 시각, 반복 요일, 색, 예고 알림·소리·진동 설정, 삭제한 알람이면 삭제한 시각 |
| 기록 | 날짜, 예정 시각, 기록 버튼을 누른 시각, 미룬 횟수 |
| 설정 | 화면 테마 (시스템 설정 따르기 · 라이트 · 다크) |

재부팅한 뒤 잠금을 한 번도 풀지 않은 상태에서도 알람이 제시각에 울리도록, Android에서는 이 데이터를
**기기 보호 저장소**(Direct Boot)에 둡니다. iOS에서도 같은 이유로 기기를 처음 한 번 잠금 해제한
뒤부터 앱이 읽을 수 있는 보호 등급으로 저장합니다. 어느 쪽이든 다른 앱이나 외부에서는 접근할 수
없는 앱 전용 영역입니다.

이름·전화번호·이메일·생년월일·위치·연락처·사진 등은 요청하지도, 저장하지도 않습니다.
알람 제목은 사용자가 직접 적은 문자열이며, 앱은 그 내용을 해석하거나 분류하지 않습니다.
기록은 사용자가 버튼을 눌러 직접 남기는 자가기록이고, 앱이 실제 복용 여부를 판단하지 않습니다.

## 외부 전송

없습니다. Android 앱은 `android.permission.INTERNET` 권한을 선언하지 않으므로 기술적으로
데이터를 외부로 보낼 수 없고, iOS 앱에도 네트워크로 데이터를 보내는 코드가 없습니다.
광고·분석·추적 SDK를 포함하지 않으며, 제3자에게 어떤 정보도 제공하거나 판매하지 않습니다.

한 가지 예외는 **사용자 본인의 기기 백업**입니다.

- Android: 기기에서 Google 백업을 켜 두었다면 알람과 기록이 사용자 본인의 Google 계정 백업에
  포함되고, 새 기기로 옮길 때 함께 복원됩니다.
- iOS: iCloud 백업이나 컴퓨터 백업을 켜 두었다면 알람과 기록이 그 백업에 포함되고, 새 iPhone으로
  옮길 때 함께 복원됩니다.

이 백업은 Google·Apple과 사용자 사이의 기능이며 앱 개발자는 해당 데이터에 접근할 수 없습니다.
원하지 않으면 기기 설정에서 이 앱의 백업을 끌 수 있습니다.

앱 안의 '리뷰 쓰기', '개인정보처리방침', '문의하기'는 사용자가 누를 때만 스토어·브라우저·메일 앱을
열 뿐이며, 앱이 그 과정에서 정보를 보내지 않습니다.

## 권한

### Android

| 권한 | 쓰는 이유 |
|------|-----------|
| 알림 (POST_NOTIFICATIONS) | 알람 알림을 띄우기 위해 |
| 정확한 알람 (SCHEDULE_EXACT_ALARM · USE_EXACT_ALARM) | 정해진 시각에 정확히 울리기 위해 |
| 전체 화면 알림 (USE_FULL_SCREEN_INTENT) | 잠금화면 위에 알람 화면을 띄우기 위해 |
| 포그라운드 서비스 (FOREGROUND_SERVICE · MEDIA_PLAYBACK) | 알람음을 끊기지 않게 재생하기 위해 |
| 부팅 완료 (RECEIVE_BOOT_COMPLETED) | 재부팅 후 알람을 다시 예약하기 위해 |
| 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW) | 다른 앱을 쓰는 중에도 알람 화면을 띄우기 위해 |
| 배터리 최적화 제외 (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) | 절전 기능에 알람이 밀리지 않게 하기 위해 |
| 진동 (VIBRATE) · 화면 깨우기 (WAKE_LOCK) | 알람 진동과 화면 켜기 |

### iOS

| 권한 | 쓰는 이유 |
|------|-----------|
| 알람 (AlarmKit) | 무음 모드나 집중 모드에서도 정해진 시각에 알람을 울리기 위해 |
| 알림 · 시간 민감 알림 | 예고 알림과 기록하지 않은 알람을 알려 주기 위해 |
| 백그라운드 앱 새로고침 | 날짜가 바뀌어도 다음 알람을 미리 예약해 두기 위해 |

모두 알람을 제 시각에 울리기 위한 용도이며, 개인정보를 읽는 데 쓰이지 않습니다.

## 데이터 삭제

- 알람 삭제: 앱 안에서 알람을 삭제하면 더 울리지 않지만, 지난 기록은 캘린더에 남습니다.
  삭제할 때 **기록도 함께 지우기**를 고르면 그 알람과 기록이 함께 지워집니다. 기록이 없는 알람은
  삭제하면 바로 지워집니다.
- 전체 삭제:
  - Android: **설정 → 애플리케이션 → 약을매일먹자 → 저장공간 → 데이터 삭제**, 또는 앱 삭제
  - iOS: 홈 화면에서 앱을 길게 눌러 **앱 삭제**
  
  어느 쪽이든 기기에 저장된 모든 데이터가 삭제됩니다.
- 개발자가 보관하는 사본이 없으므로, 개발자에게 삭제를 요청할 데이터도 없습니다.
